## [Unreleased]

### Added

- A single-file 3D studio that renders a macOS-style IDE window as a lit Three.js scene.
- Syntax highlighting for TypeScript, HTML, CSS, Python, and Rust.
- Six editor colour themes, including light and high-contrast options.
- IDE font choices, adjustable font size and line spacing, and quick theme and
  font cycling controls.
- Five camera views, orbit navigation, zoom controls, and a viewport navigation
  gizmo.
- Five lighting setups and five scene backgrounds.
- Optional `[[bracketed]]` 3D code text with adjustable extrusion height.
- PNG export named after the window title.
